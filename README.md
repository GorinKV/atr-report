# 📈 ATR Report Service

Сервис для аналитики волатильности и генерации отчетов по индикатору **ATR (Average True Range)** на базе данных Московской Биржи (MOEX) и Tinkoff Invest API.

## 🛠 Технологический стек
* **Язык:** Python 3.12+
* **Веб-фреймворк:** FastAPI, Uvicorn
* **Работа с данными:** Pandas, NumPy
* **Сторонние API:** MOEX ISS (свечи), Tinkoff Invest API (FIGI, стакан)
* **Тестирование:** Pytest, Pytest-asyncio
* **База данных (опционально):** MariaDB / MySQL (для фонового поллера плотностей)

## ✨ Возможности
* 📊 **Расчет ATR:** Вычисление Average True Range по историческим данным свечей с заданным периодом.
* 🚦 **Классификация волатильности:** Умное определение уровней (Низкая, Норма, Высокая) с визуализацией.
* 🔄 **Асинхронный парсинг:** Быстрая загрузка данных с MOEX ISS и Tinkoff API с кэшированием FIGI.
* 🌐 **Веб-интерфейс:** Раздача статических HTML-страниц для визуального отображения отчетов.
* 🧪 **Покрытие тестами:** Юнит-тесты на бизнес-логику и API (изолированы от сети).

## 🚀 Быстрый старт

### 1. Подготовка окружения
Рекомендуется использовать изолированное виртуальное окружение:

~~~
# Клонирование репозитория
git clone https://github.com/GorinKV/atr-report.git
cd atr-report

# Создание и активация venv
python3 -m venv venv
source venv/bin/activate
~~~

Установка зависимостей:
~~~
pip install -r requirements.txt
pip install -r requirements-dev.txt
~~~

### 2. Запуск приложения
Для локального запуска сервера используется Uvicorn:

~~~
uvicorn main:app --reload --host 0.0.0.0 --port 8000
~~~

* **Веб-интерфейс:** http://127.0.0.1:8000
* **Swagger UI (Документация API):** http://127.0.0.1:8000/docs

## 🧪 Тестирование
В проекте настроен Pytest. Для удобства создан bash-скрипт `t`, который автоматически активирует `venv` и запускает тесты:

~~~
./t        # Обычный запуск
./t -rs    # Запуск с подробной информацией о пропущенных тестах
~~~
*Тесты используют моки и Pandas-фикстуры, поэтому не требуют доступа к интернету и работают за доли секунды.*
